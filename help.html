📖 Getting Started

What is Oracare Fulfillment?

Oracare Fulfillment is a fulfillment system that syncs orders from ShipStation, tracks shipments, and manages inventory. The system runs 24/7 with minimal manual intervention.

How It Works

  1. Order Sync: Orders are automatically synced from ShipStation every 5 minutes
  2. Lot Tagging: Orders are tagged with the correct lot numbers for deduction
  3. Status Tracking: System monitors order status (awaiting shipment → shipped)
  4. Inventory Update: When orders ship, inventory is automatically updated

Your Main Tasks

  • Monitor Dashboard: Check that orders are processing smoothly
  • Handle Alerts: Review shipping violations and inventory warnings
  • Generate Reports:
    • EOW (End of Week) - Weekly inventory report for manufacturer & customer
    • EOM (End of Month) - Monthly chargeback report for customer

✅ Common Tasks

📊 Monitor Daily Operations

  1. Go to the Dashboard
  2. Check the KPI cards:
    • ShipStation Units - Orders in ShipStation awaiting shipment
    • Local DB Units - Orders ready to upload to ShipStation
    • Benco Orders - Benco-specific orders awaiting shipment
    • Hawaiian Orders - Hawaiian orders awaiting shipment
  3. Green status = everything normal, Yellow/Red = needs attention

🔍 Look Up or Reconcile an Order

  1. Click Order Management in the sidebar
  2. Enter the order number and click Search
  3. Compare the ShipStation record with the local DB record
  4. Use Sync from SS to pull the latest ShipStation data into the local DB

📈 Generate Weekly Report (EOW)

  1. Go to the Dashboard
  2. Scroll to "Weekly Inventory Report" section
  3. Click the 📊 EOW button
  4. Report generates with 52-week averages
  5. Share with manufacturer and customer

Do this every Friday or at week-end

💰 Generate Monthly Chargeback Report (EOM)

  1. Go to the Dashboard
  2. Scroll to "Weekly Inventory Report" section
  3. Click the 💰 EOM button
  4. Chargeback report generates
  5. Send to customer for billing

Do this at end of each month

⚠️ Handle Shipping Violations

  1. When alert appears at top of dashboard, click View Details
  2. Review violation (e.g., "Hawaiian order used USPS instead of FedEx 2Day")
  3. Check if it's acceptable or needs correction
  4. Click Mark as Resolved when handled

🏭 Check Inventory Levels

  1. Click Lot Inventory in sidebar
  2. Review current quantities by SKU and lot
  3. Red badges (e.g., "11 days") = low inventory warning
  4. Green badges (e.g., "226 days") = healthy stock

❓ Frequently Asked Questions

How often do orders sync automatically?

Every 5 minutes. The system polls ShipStation for new and updated orders continuously.

What if an order doesn't appear?

Use Order Management to look up the order number. If it exists in ShipStation but not locally, use the "Sync from SS" button to pull it in.

When should I click EOD vs EOW vs EOM?

  • EOD (End of Day): Syncs shipped items - run daily or when needed
  • EOW (End of Week): Generates weekly inventory report - run every Friday
  • EOM (End of Month): Generates chargeback report - run at month-end

What's the difference between "ShipStation Units" and "Local DB Units"?

ShipStation Units: Orders in ShipStation currently awaiting shipment (live from the API).
Local DB Units: Orders synced into the local database — should match ShipStation closely after each 5-minute sync cycle.

Why is there a shipping violation?

The system detected an order shipped with incorrect carrier/service (e.g., Hawaiian orders must use FedEx 2Day). Review and resolve if needed.

Can I manually add an order?

Orders come in through ShipStation automatically. If an order is missing locally, use Order Management → Search → "Sync from SS" to pull it in. To create a brand-new order, create it directly in ShipStation and it will sync within 5 minutes.

What happens if inventory runs out?

The system shows red warning badges (e.g., "11 days left"). Coordinate with manufacturer to restock before it hits zero.

🔧 Troubleshooting

❌ Order shows "FAILED" status

Possible causes:

  • Missing or invalid SKU-Lot mapping
  • ShipStation API error during sync
  • Duplicate order conflict

Solution:

  1. Go to Order Management and look up the order to see the failure reason
  2. Verify the lot assignment exists (go to Lot Inventory, then open Lot Assignments)
  3. Use "Sync from SS" to pull the latest data from ShipStation

⏸️ Order not appearing locally after it's in ShipStation

Possible causes:

  • Sync hasn't run yet (runs every 5 minutes)
  • ShipStation sync workflow paused

Solution:

  1. Wait up to 5 minutes for the next automatic sync
  2. Check Workflow Controls — ensure "ShipStation Sync" is ON
  3. Use Order Management → "Sync from SS" to pull the order immediately

📉 KPI numbers look wrong

Solution:

  1. Click the "Refresh" button in dashboard header
  2. Wait for auto-refresh (happens every 30 seconds)
  3. Check "Last updated" timestamp under each KPI

🔴 System Status shows "Warning"

Solution:

  1. Click on the System Status card to see details
  2. Check if workflows are running (Workflow Controls page)
  3. Review recent error logs if available
