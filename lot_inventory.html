🏭 Lot Inventory Monitor

📦 Transaction-Based FIFO Inventory
Balance is computed live from all inventory transactions (Receive, Ship, Adjust Up/Down, Repack) linked to each lot. Lots are sorted by received date (oldest first per SKU). Use Record Correction to post an adjustment for a specific lot.

Lot assignments used by the lot tagger to determine which lot number to stamp on new orders per SKU. Only Active assignments are used by the tagger. To retire an assignment, Deactivate it — do not delete the underlying lot record. Assignments do not receive stock or release backorders; use Lot Inventory to record a receipt.
