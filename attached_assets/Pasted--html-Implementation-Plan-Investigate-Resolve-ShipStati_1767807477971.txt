### EXECUTIVE SUMMARY

This task aims to identify and resolve a duplicate key error occurring during ShipStation synchronization within the Oracare Fulfillment App. The error prevents orders from being correctly processed, impacting fulfillment accuracy and efficiency.

    • Implement fix to prevent future duplicate key errors.

    • Process affected orders (100859, 100594).

Estimated complexity: Medium

### Current Limitations

We need to assess the current error handling mechanisms. Are there sufficient logs to diagnose the problem? Is there a retry mechanism in place for failed synchronizations? Is there input validation and sanitization to prevent invalid data from being inserted into the database?

### PHASE 2: IMPLEMENTATION PLAN

### Architecture Overview

The ShipStation sync service fetches order data from ShipStation, transforms it, and attempts to insert or update records in the Oracare Fulfillment App's database. The duplicate key error suggests that the same ShipStation order ID is being inserted multiple times into the `manual_order_conflicts` table.

The fix will involve adding a check to see if a record with the same ShipStation order ID already exists in the `manual_order_conflicts` table before attempting to insert a new record. If a record exists, we should either update the existing record or skip the insertion, depending on the desired behavior.

async function syncOrder(shipStationOrder: ShipStationOrderType) {
  const existingConflict = await ManualOrderConflict.findOne({
    where: { shipstationOrderId: shipStationOrder.orderId },
  });

  if (existingConflict) {
    logger.warn(`Duplicate ShipStation order ID ${shipStationOrder.orderId} found. Skipping insertion.`);
    // Optionally, update the existing record instead of skipping:
    // await ManualOrderConflict.update({ ... }, { where: { id: existingConflict.id } });
    return;
  }

  try {
    await ManualOrderConflict.create({
      shipstationOrderId: shipStationOrder.orderId,
      // Other relevant data
    });
    logger.info(`Successfully synced order ${shipStationOrder.orderId}`);
  } catch (error) {
    logger.error(`Error syncing order ${shipStationOrder.orderId}: ${error}`);
    throw error;
  }
}
